Как пользоваться дорожными картами

Краткая инструкция по работе с дашбордом и Excel-файлом

Инструмент работает локально в браузере: загружает дорожные карты из Excel, показывает состояние задач и позволяет сохранить обновлённую копию книги.

Быстрый старт

  1. Откройте Excel-файл. При первом запуске нажмите «Выбрать Excel-файл». После загрузки заменить источник можно через шестерёнку справа внизу.
  2. Посмотрите общую картину. «Дашборд всех карт» показывает прогресс, план, выполнение и задачи, требующие внимания.
  3. Откройте нужную карту. Используйте список «Дорожная карта» и поиск в левой панели.
  4. Выберите период. Справа сверху доступны все периоды, отдельный год или квартал. Если в файле только один год, будет показан вариант «Все кварталы».
  5. Внесите результат. Внутри карты нажмите карандаш в блоке статуса. Для количественной карты выберите неделю, для этапной — этап; затем укажите выполнение и при необходимости комментарий.
  6. Создайте новую карту. В окне «Новая дорожная карта» выберите количественный или этапный формат. В этапном формате каждый этап добавляется отдельно: укажите дату начала, длительность и при необходимости повторение.
  7. Создайте собственную структуру. Откройте «Конструктор карт», задайте поля, период и измеритель прогресса. Новые карты доступны рядом с Excel-картами.
  8. Подключите готовую таблицу Excel. Выберите «Импортировать таблицу Excel», укажите лист, строку заголовков и столбец периода, затем сопоставьте остальные столбцы и роли.
  9. Сохраните изменения. Откройте шестерёнку и нажмите «Скачать Excel». Исходный файл не перезаписывается — создаётся обновлённая копия.

Универсальные карты

  • В конструкторе задаются собственные поля разных типов и временная шкала по неделям, месяцам или кварталам.
  • Числовые поля отображаются на графике динамики. Роль «План» и «Факт» позволяет автоматически считать прогресс; либо задайте поле «Прогресс» в процентах.
  • Значения редактируются в таблице карты и сохраняются в этом браузере. Для переноса на другой компьютер используйте «Сохранить файл конструктора» и затем «Загрузить файл конструктора».
  • Готовую таблицу можно импортировать кнопкой «Импортировать таблицу Excel»: выберите лист, строку заголовков, поле периода и назначьте типы и роли столбцов.
  • Для переноса универсальных карт между браузерами сохраните JSON-файл и загрузите его на другом компьютере. Excel-книга исходных карт не изменяется.

Количественные карты

  • Используются для задач, измеряемых в штуках или другом количестве.
  • В поле выполнения вводится накопительный итог на конец выбранной недели.
  • Для прошедшего периода факт сравнивается с итоговым планом, для текущего — с планом на текущую неделю, а будущий период получает статус «Запланировано».
  • При выборе года показываются значения только этого года; «Все периоды» показывает общий итог по многолетней карте.

Этапные карты

  • Новые этапные карты строятся из отдельных задач. Если начинать с текущего квартала, первая дата приходится на первую неделю этого квартала.
  • Для каждого этапа отдельно задаются дата, длительность в днях, неделях или месяцах, частота повторения и число повторов. Порядковый номер назначается автоматически по сроку.
  • В календаре этапы можно перетаскивать на другую неделю. Переключатель определяет, сдвигать ли вслед за выбранным этапом все последующие; через «Управление этапами» можно добавлять, менять и удалять этапы даже после создания карты.
  • План сохраняется в загружаемую Excel-копию; при повторном открытии созданной таким способом книги этапы остаются редактируемыми.
  • В редакторе вводится процент от 0 до 100: 100% означает полное выполнение, 50% — половину этапа.
  • Объединённый на несколько недель блок считается одним этапом; отметка сохраняется в верхнюю ячейку соответствующего объединённого диапазона Excel.
  • Прошедший этап с результатом меньше 100% считается просроченным.
  • Комментарий не показывается в основной ленте этапов: он доступен только в нижнем блоке «Данные этапной карты» и не меняет статус.
  • Значение выше 100% считается ошибкой исходных данных и показывается красным предупреждением.

Как читать статусы

  • Зелёный — выполнено или работа идёт по плану.
  • Синий — опережение плана, активная работа или частичное выполнение текущего этапа.
  • Оранжевый/красный — отставание или просроченный этап.
  • Серый — нет планового значения, недостаточно данных или этап ещё запланирован.
Важно: изменения сначала существуют только в открытом дашборде. Чтобы передать их коллегам или сохранить для следующей работы, скачайте обновлённый Excel через меню настроек.

Новая дорожная карта

Создайте задачу в дашборде и скачайте обновленный Excel.

«Количественная» и «Этапная» используют проверенную структуру соответствующего листа исходной книги.
Для количественной карты строки попадут в колонку «Комментарий». Для этапной карты - в колонку «План».
Этапы плана
У каждого этапа свой срок, длительность и повторение. Нумерация назначается автоматически.

Новый этап

Настройте срок и повторение этого этапа отдельно.

Редактирование этапов

Добавляйте, меняйте сроки, частоту или удаляйте этапы.

Конструктор дорожной карты

Опишите структуру и правила расчёта. Поля и значения можно будет менять в самой карте.

Поля данных
Для прогресса назначьте числовым полям роли «План» и «Факт» или добавьте поле «Прогресс, %». Другие числовые поля тоже попадут в график.

Импорт Excel как дорожной карты

Сопоставьте столбцы таблицы с периодом и полями карты.

Поля данных
Снимите флажки у ненужных столбцов. Для расчёта прогресса выберите роли «План» и «Факт» либо «Прогресс, %».

Обновить текущий прогресс

Укажите накопительный факт на выбранную неделю.

Отчёт для руководителя

Проверьте текст, затем скопируйте его или откройте готовое письмо.

Можно указать несколько адресов через запятую или точку с запятой.

Фильтры отчёта

Изменение фильтра автоматически пересобирает текст отчёта. Основной дашборд при этом не меняется.
Текст можно отредактировать перед отправкой.

Сообщить о проблеме

Опишите ситуацию — обращение сохранится отдельным текстовым файлом в выбранной папке bugs.

Сначала выберите папку bugs в левой панели. Контекст дашборда добавится автоматически.
