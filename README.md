# Дашборд прогресса дорожных карт

Локальный инструмент для просмотра дорожных карт из Excel: он показывает прогресс задач, сравнивает факт с квартальным и годовым планом, позволяет создавать новые карты, вносить прогресс и готовить отчёт для руководителя.

## Возможности

- Загрузка дорожных карт из Excel (`.xlsx`, `.xls`, `.xlsm`, `.csv`).
- Сводная страница со статусами: выполнено, по плану, опережение, отставание и нет данных.
- Просмотр прогресса по кварталам и задачам.
- Адаптивные карточки и графики для широких экранов, ноутбуков, планшетов и узких окон.
- Создание новой дорожной карты и экспорт обновлённой книги Excel.
- Внесение накопительного факта по неделям для количественных карт и процентов выполнения по этапам для этапных карт.
- Формирование понятного отчёта для руководителя: копирование текста или открытие готового черновика письма в почтовом клиенте.
- Сообщение о проблеме с сохранением отдельного TXT-файла в выбранной общей папке `bugs`.

## Быстрый старт

1. Скачайте или клонируйте репозиторий целиком: папка `vendor` обязательна для работы с Excel и графиками.
2. Откройте `task-progress-dashboard.html` двойным кликом в Google Chrome или Microsoft Edge.
3. На стартовом экране левой панели выберите рабочий Excel-файл. Там же доступны создание карты по прежнему шаблону, универсальный конструктор, импорт таблицы Excel с сопоставлением полей и сообщение о проблеме.
4. После загрузки откройте `Дашборд всех карт` либо найдите отдельную карту через поисковый список. Остальные действия, экспорт и источник данных находятся в выдвижной панели под шестерёнкой `Настройки и действия`.

Кнопка `?` в левом нижнем углу открывает встроенную справку по загрузке файла, навигации, статусам, внесению прогресса и сохранению обновлённого Excel. Она доступна как до загрузки книги, так и во время работы.

## Правило обновления встроенной справки

После любого значимого пользовательского изменения необходимо одновременно обновлять содержимое окна Help (`#helpModal` в `task-progress-dashboard.html`). Это относится к новым функциям, кнопкам, статусам, расчётам, форматам Excel и изменению последовательности действий пользователя.

Изменение считается завершённым только после трёх проверок:

1. Новая или изменённая возможность описана понятным языком во встроенной справке.
2. Инструкция соответствует фактическим названиям кнопок, полей и статусам интерфейса.
3. При необходимости актуализированы `README.md` и `handoff.md`.

Чистый внутренний рефакторинг без изменения поведения пользователя добавлять в Help не требуется.

Инструмент работает локально: сервер, установка Python и подключение к интернету не требуются.

## Быстрый доступ к сетевой папке

Если файл дорожной карты находится по длинному пути на сетевом диске, нажмите «Открыть Excel-файл» и один раз выберите сам файл. При следующем запуске эта же кнопка откроет сохранённый файл напрямую. При необходимости используйте компактную ссылку «Сменить файл».

Настройка сохраняется только локально в браузере конкретного пользователя: один и тот же HTML-файл могут использовать коллеги с разными буквами сетевых дисков. Для функции нужны Google Chrome или Microsoft Edge; при новом запуске браузер может запросить подтверждение доступа к папке.

## Формат Excel

Для стандартных листов заголовки находятся в строке 3:

| Колонка | Содержимое |
| --- | --- |
| A | Квартал |
| B | Неделя |
| C | Начало недели |
| D | Конец недели |
| E | Квартальный план |
| F | Годовой план |
| G | Квартальный прогресс |
| H | Годовой прогресс |
| I | Выполнено |
| J | Комментарий |

Название задачи читается из первой строки листа, ответственный — из ячейки `A2`.

### Этапные дорожные карты

Инструмент автоматически распознаёт этапную карту по содержимому: в колонке плана находятся текстовые этапы, а числовой план отсутствует. Числом считается только целиком числовое содержимое ячейки: нумерованные пункты вроде `1. Подготовить список` остаются текстовыми этапами. Название файла, листа и точная формулировка заголовка на распознавание не влияют.

Для этапных карт показываются количество запланированных и выполненных этапов, процент выполнения и хронологический список плана. Статус этапа определяется по сроку и числовой отметке выполнения: будущий этап считается запланированным, текущий — находящимся в работе, а прошедший с выполнением меньше 100% — просроченным. Состояние `Частично` применяется к много-недельному этапу с выполнением от 1% до 99%, пока его срок ещё не закончился. Комментарий доступен только в нижнем блоке `Данные этапной карты` и на статус не влияет. Количественные карты продолжают рассчитываться по прежней логике.

В редакторе этапной карты выбирается этап, а выполнение вводится в процентах от 0 до 100. Значение выше 100% в исходном Excel считается ошибкой данных и не засчитывается как завершённый этап. При сохранении выполнение и комментарий записываются в верхние ячейки соответствующих объединённых диапазонов.

В показателе `Выполнено` учитываются только этапы с отметкой 100%. Частичная отметка не превращается в дробное количество выполненных этапов: она учитывается в проценте общего прогресса и отдельно показывается внутри этапа.

Новые этапные карты можно собирать по одному этапу за раз. У этапа задаются дата начала, длительность в днях/неделях/месяцах, периодичность (разово, еженедельно, раз в две недели, ежемесячно или ежеквартально) и число повторов. Этапы нумеруются автоматически по дате начала. При создании с текущего квартала первый этап предлагается на первой неделе текущего квартала. После создания этапы доступны в календаре: их можно перетаскивать на другую неделю, включить или отключить автосмещение последующих этапов, а также добавлять, редактировать и удалять через управление этапами. Расписание новых карт и созданных ими Excel-копий сохраняет метаданные для повторного редактирования. Существующие карты из произвольных исходных книг продолжают открываться в прежнем формате.

Объединённые ячейки этапной карты учитываются как единый диапазон. Если план, выполнение и комментарий начинаются с разных строк, но их объединённые диапазоны пересекаются, они собираются в одну запись этапа. В нижней таблице объединения воспроизводятся визуально через диапазоны строк.

## Расчёты и статусы

- Годовой план берётся из колонки `F`; он не восстанавливается по процентам прогресса.
- Процентные значения из `G` и `H` читаются с исходной точностью Excel, включая значения выше 100%.
- При выборе конкретного квартала «Выполнено за квартал» равно накопительному факту последней заполненной недели квартала минус факт последней заполненной недели предыдущего квартала.
- Для прошедшего квартала статус сравнивает факт с итоговым квартальным планом; для текущего — с планом на текущую неделю; будущий квартал получает статус `Запланировано`.
- Если книга содержит несколько лет, фильтр предлагает `Все периоды`, каждый год целиком и отдельные кварталы. Годовой режим показывает прирост плана и факта только выбранного года, а `Все периоды` — общий накопительный итог.
- В агрегированном режиме статус темпа сравнивает факт с планом на текущую неделю, если период уже начался.

Статусы: «Отстаём», «Идём по плану», «Перевыполняем», «Нет данных», «Выполнено» и «Перевыполнено».

## Завершение задачи

Достижение числового плана само по себе не закрывает задачу: работа может продолжаться и при факте выше годового плана. Чтобы явно закрыть задачу, в комментарии (`J`) последней строки с фактом укажите `[ЗАВЕРШЕНО]` (также допускается `Завершено`).

Закрытая задача с фактом выше годового плана получает статус «Перевыполнено», иначе — «Выполнено».

При выборе квартала инструмент учитывает период закрытия. В кварталах до закрытия показывается историческое состояние задачи, в квартале закрытия — итоговый результат, а в последующих кварталах — статус «Выполнено ранее» без неактуального квартального остатка и графиков.

## Отображение на разных экранах

Карточки и панели перестраиваются по ширине окна. На недельных графиках при нехватке места автоматически показывается меньше подписей оси, при этом все точки и значения остаются доступны при наведении. Сводные графики с длинными названиями задач сохраняют все подписи и получают горизонтальную прокрутку внутри панели.

## Новая дорожная карта в основной книге

После загрузки основной книги в мастере «Новая дорожная карта» выберите шаблон `Количественная` или `Этапная`. Инструмент автоматически привязывает каждый вариант к реальному исходному листу соответствующего типа. При экспорте новый лист копирует его структуру, формулы и объединения, но создаётся без цветных заливок; данные записываются в фактические колонки выбранного шаблона. Лист добавляется последней страницей в файл `*_updated.xlsx`.

Созданную задачу можно сразу открыть в инструменте и через кнопку «Внести правки» указать накопительный факт и комментарий по выбранной неделе. При экспорте они записываются в новый лист.

Исходная книга не изменяется: инструмент всегда скачивает отдельную обновлённую копию. Если книга не была загружена, новая карта экспортируется в упрощённой структуре без формул шаблона.

## Конструктор универсальных карт

Кнопка `Конструктор карт` создаёт карту с собственным набором полей и временной шкалой. Можно выбрать шаг `Неделя`, `Месяц` или `Квартал`, диапазон до 21 года, название, ответственного и описание. Для каждого поля задаются имя, тип (`Число`, `Процент`, `Текст`, `Дата`, `Статус`) и при необходимости роль:

- `План` и `Факт` — для автоматического расчёта прогресса как отношения факта к плану;
- `Прогресс, %` — если прогресс уже вводится напрямую;
- `Без роли` — произвольные атрибуты карты.

Каждое числовое поле получает отдельный график, чтобы показатели с разными единицами не смешивались. Значения вводятся в таблице карты. Структуру можно изменить через `Изменить структуру`; при несовместимом изменении приложение предупредит о потере части значений.

Кнопка `Импортировать таблицу Excel` позволяет прочитать произвольный лист из `.xlsx`, `.xls`, `.xlsm` или `.csv`. В мастере укажите лист, строку заголовков и столбец периода, затем отметьте столбцы данных и назначьте типы и роли. Приложение не угадывает смысл неизвестных данных молча: автоматические предложения нужно проверить перед импортом.

Универсальные карты хранятся локально в браузере и остаются доступны при следующем открытии дашборда на том же компьютере и в том же браузере. Для переноса между пользователями или резервной копии используйте `Сохранить файл конструктора` и `Загрузить файл конструктора`. Такой файл содержит JSON-описание и данные универсальных карт. Универсальные карты пока не добавляются в исходную Excel-книгу; их данные сохраняются в браузере или JSON-файле. Существующий Excel-сценарий продолжает работать отдельно.

## Пустое состояние и стартовая страница

Когда нет открытых карт, инструмент очищает рабочую область и показывает стартовую страницу с действиями: открыть Excel, создать количественную или этапную карту, открыть конструктор, импортировать таблицу Excel либо загрузить JSON конструктора. Примерные карты и демонстрационные данные не создаются. После создания карты приложение остаётся на общем обзоре; карту можно открыть из списка. Последнее содержимое удалённой карты не остаётся на экране.

## Отчёт для руководителя

Нажмите «Отчёт для руководителя», проверьте сформированный текст и при необходимости измените его. Кнопка «Открыть письмо» создаёт черновик через `mailto:` в почтовой программе по умолчанию. Письмо не отправляется автоматически — отправку подтверждает пользователь.

Средний прогресс отчёта рассчитывается только по картам, для которых достаточно данных; задачи со статусом `Нет данных` в среднее не входят.

## Сообщение о проблеме

1. В левой панели нажмите «Сообщить о проблеме».
2. В открывшемся окне нажмите «Выбрать папку bugs» и укажите заранее созданную общую папку для обращений.
3. Подтвердите браузеру разрешение на запись.
4. Заполните форму и нажмите «Отправить сообщение».

Каждое сообщение сохраняется отдельным файлом `bug-ГГГГММДДЧЧММСС-идентификатор.txt`. Это позволяет нескольким сотрудникам одновременно оставлять обращения без конфликтов. Для функции нужны Chrome или Edge и права записи в выбранную папку. После нового открытия дашборда папку потребуется выбрать снова.

## Что не попадает в репозиторий

Рабочие Excel-файлы и содержимое папки `bugs` намеренно исключены из Git, так как могут содержать служебные данные. Передавайте их через разрешённое корпоративное хранилище.
