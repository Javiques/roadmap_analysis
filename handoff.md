# Handoff: инструмент анализа дорожных карт

## Назначение

Инструмент показывает прогресс дорожных карт из Excel-файла в виде локального HTML-дашборда. Он помогает быстро понять:

- какие задачи идут по плану;
- какие задачи отстают;
- какие задачи перевыполняются;
- какие задачи уже выполнены;
- как факт соотносится с квартальным и годовым планом.

## Основные файлы

- `task-progress-dashboard.html` - основной интерфейс, вся логика чтения Excel, расчетов и графиков находится здесь.
- `dk.main.xlsx` - текущий рабочий/эталонный Excel-файл для проверки; не менять без отдельного явного запроса.
- `vendor/chart.umd.min.js` - локальный Chart.js.
- `vendor/xlsx.full.min.js` - локальный SheetJS для чтения Excel.

## Технологии

- HTML/CSS/vanilla JavaScript.
- Chart.js для графиков.
- SheetJS/XLSX для чтения Excel в браузере.
- Python используется только для внешней проверки Excel при необходимости:

## Важная структура Excel

Для стандартных листов ожидается структура:

- `A3` - `Квартал`
- `B3` - `Неделя`
- `C3` - `Начало недели`
- `D3` - `Конец недели`
- `E3` - `Квартальный план`
- `F3` - `Годовой план`
- `G3` - `Квартальный прогресс`
- `H3` - `Годовой прогресс`
- `I3` - `Выполнено`
- `J3` - `Комментарий`

Описание задачи читается из первой строки листа.
Ответственный читается из `A2`.

## Текущая логика выполнения

`Выполнено` в Excel считается накопительно с начала года.

Чтобы не вводить в заблуждение при выборе конкретного квартала, инструмент считает отдельную величину:

```text
Выполнено за квартал = выполнено сейчас - выполнено на конец прошлого квартала
```

Пример для `Тираж / Q2`:

```text
Конец Q1: 91
Конец Q2: 212
Выполнено за Q2: 212 - 91 = 121
Квартальный план Q2: 221
Осталось: 100
```

В режиме `Все кварталы` остается накопительное `Выполнено`, потому что сравнение идет с годовым планом.

## Типы дорожных карт

При загрузке лист автоматически классифицируется по содержимому, без привязки к имени файла или листа:

- `quantitative` — есть числовой квартальный или годовой план; используется исходная количественная логика и единицы `шт`;
- `stage` — есть текстовые пункты плана и нет числовой плановой кривой; используется этапное представление.

Для этапной карты:

- текст плана берётся из найденной колонки квартального плана или `План`;
- описание хода работ собирается из текстового прогресса, текстового значения `Выполнено` и комментария;
- положительные числовые отметки `Выполнено` суммируются внутри выбранного периода;
- прогресс равен отношению суммы отметок выполнения к количеству текстовых этапов;
- экран задачи показывает отдельную временную шкалу этапов вместо количественных графиков;
- статусы этапов: `Запланировано`, `В работе`, `Просрочено`, `Частично`, `Выполнено`; комментарий на статус не влияет;
- показатель `Выполнено` считает только этапы с отметкой 100%; значения от 1% до 99% участвуют в расчёте прогресса, но не выводятся как дробное количество завершённых этапов;
- количественные и этапные абсолютные показатели выводятся на разных сводных графиках, чтобы не смешивать этапы со штуками.

## Статус плана

Добавлен статус относительно плана:

- `Отстаем`
- `Идем по плану`
- `Перевыполняем`
- `Нет данных`
- `Выполнено`
- `Перевыполнено`

Логика:

- в режиме `Все кварталы` факт сравнивается с годовым планом на текущую заполненную неделю;
- при выборе конкретного квартала факт за квартал сравнивается с итоговым квартальным планом;
- годовой план из колонки `F` имеет приоритет над любым восстановлением по проценту;
- проценты из Excel читаются как исходные значения, поэтому `1,027` в процентной ячейке означает `102,7%`;
- задача считается завершённой только при маркере `[ЗАВЕРШЕНО]` или `Завершено` в комментарии последней строки с фактом;
- у завершённой задачи основной статус — `Выполнено`, а при факте выше годового плана — `Перевыполнено`;
- завершение учитывается во времени: кварталы до строки с маркером показывают исторический статус, квартал завершения — итоговый результат, а более поздние кварталы — состояние `Выполнено ранее` без расчёта нового остатка и без квартальных графиков.

В карточках задач статус темпа отображается маленьким цветным кружком:

- оранжевый - `Отстаем`;
- зеленый - `Идем по плану`;
- синий - `Перевыполняем`;
- серый - `Нет данных`.

При наведении на кружок показывается только короткий статус.
Текст причины, например `Отставание от плана: 77`, показывается внутри карточки.

## Карточки задач

В режиме `Все задачи` сверху показываются карточки задач.

В карточке:

- название задачи;
- ответственный;
- прогресс;
- цветная полоса прогресса в цвет статуса;
- короткие метрики;
- статусный кружок для незавершенных задач;
- зеленый бейдж `Выполнено` для завершенных задач.

Строка ответственного резервируется во всех карточках. Если `A2` пустая, выводится нейтральный текст `Ответственный: не указан`, поэтому прогресс, статус и нижние показатели соседних карточек остаются выровненными.

Для состояния `Выполнено ранее` нижний блок содержит только `Итоговый факт` и квартал завершения. Дата не дублируется отдельной метрикой и остаётся в строке пояснения о завершении.

Если у задачи есть описание, карточка переворачивается по клику. На обратной стороне показывается только описание, без повторения названия задачи и без ответственного.

## Графики

Цвета количественных серий: `Квартальный план` — синий, `Годовой план` — оранжевый, `Выполнено` / `Выполнено за квартал` — зелёный.
Подсказки графиков работают в режиме общей недели: при наведении одновременно показываются все доступные серии для одной позиции по оси X, что позволяет сравнивать близкие или пересекающиеся значения.

Адаптивность графиков:

- каждый `canvas` размещён в отдельном контейнере `.chart-frame` с устойчивой адаптивной высотой;
- недельная ось использует автоматический пропуск части подписей на узких экранах, но данные и tooltip остаются полными;
- сводные графики рассчитывают минимальную ширину по количеству задач и при нехватке места прокручиваются внутри `.chart-scroll`;
- при ширине до `1250px` квартальные графики перестраиваются в одну колонку;
- при ширине до `520px` уменьшаются внутренние отступы и сетка карточек принудительно занимает одну колонку.

Обзор `Дашборд всех карт`:

- график `Прогресс по задачам` показывает процент для обоих типов карт;
- абсолютные значения разделены по единицам измерения;
- график количественных карт сравнивает годовой или квартальный план с выполнением в `шт`;
- отдельный график этапных карт сравнивает количество этапов в плане с выполненными этапами;
- при выборе квартала все три представления используют только строки выбранного периода.

Страница конкретной задачи:

- верхняя карточка `Статус плана` стоит первой;
- при выборе квартала графики используют `Выполнено за квартал`;
- при выборе `Все кварталы` нижний график разделен на 4 блока: `Q1`, `Q2`, `Q3`, `Q4`;
- в квартальных блоках порядок серий: `Квартальный план`, `Годовой план`, `Выполнено за квартал`.

Страница этапной задачи:

- количественные графики не создаются;
- сверху показываются статус этапов, выполнено, всего в плане и процент прогресса;
- ниже выводится хронологический список `План, выполнение и комментарии` с кварталом, неделей и диапазоном дат;
- каждая плановая запись получает состояние `Запланировано`, `В работе`, `Просрочено`, `Частично` или `Выполнено`: завершившийся этап с результатом меньше 100% считается просроченным, а `Частично` используется для ещё не закончившегося много-недельного этапа с результатом от 1% до 99%;
- комментарии отображаются отдельно и не влияют на статус строки или карты;
- пересекающиеся объединённые диапазоны `План`, `Выполнено` и `Комментарий` собираются в единый этап с общим диапазоном недель;
- исходные строки доступны в раскрывающемся блоке `Данные этапной карты` с теми же колонками `План`, `Выполнено`, `Комментарий`, что и в Excel.

На общем дашборде названия карточек всегда занимают одну строку. Длинные названия сокращаются многоточием и плавно прокручиваются при наведении; полный текст также доступен в стандартной подсказке браузера.

В левом нижнем углу боковой панели постоянно доступна кнопка `?`. Она открывает встроенную справку с быстрым стартом, различиями количественных и этапных карт, расшифровкой статусов и напоминанием о скачивании обновлённой копии Excel. Шестерёнка остаётся справа и появляется после загрузки карты.

Затем при необходимости обновляются `README.md` и этот `handoff.md`. Внутренние технические изменения, не влияющие на действия и ожидания пользователя, в Help добавлять не нужно.

## Важные ограничения

- `dk.main.xlsx` не менять без явного запроса.
- Если рабочий Excel открыт в Excel, Windows может блокировать запись. Не пытаться обходить это силой.
- Не удалять lock-файлы вида `~$*.xlsx`; они означают, что соответствующий Excel-файл открыт.
- Распознавание типа карты основано на содержимом плана, поэтому имена файлов и листов могут быть произвольными при сохранении внутренней структуры.

## Проверка

Для быстрой проверки HTML обычно достаточно открыть страницу в headless Chrome и убедиться, что она загружается без ошибки.

Пример проверяемых признаков:

- `<title>Дашборд прогресса задач</title>`
- `Выбрать файл`
- `Загрузите Excel-файл`

После headless-проверок временные профили Chrome нужно удалять из рабочей папки.

Последняя структурная проверка `dk.main.xlsx` определила 15 рабочих листов: 7 количественных и 8 этапных. Дополнительно проверены разбор HTML, отсутствие дублирующихся `id` и отсутствие временных smoke-файлов/профилей. В текущей тестовой среде headless Chrome может аварийно завершаться на запуске GPU-процесса; это ограничение среды, поэтому расчёты книги проверялись отдельно от визуального запуска браузера.

## Создание новых дорожных карт

Текущая реализация безопасная: инструмент не пишет напрямую в исходный Excel.

Процесс:

1. Пользователь загружает Excel или создает карту без загрузки файла.
2. Нажимает `Новая дорожная карта`.
3. Заполняет мастер.
4. Новая задача появляется в `state.tasks`, карточках, фильтрах, графиках и списке выбора карты.
5. Для сохранения пользователь нажимает `Скачать Excel`.

Если был загружен исходный Excel, мастер предлагает выбрать лист-образец формул из первых двух основных ДК. Экспорт создает копию книги, переносит в новый лист формулы, границы и форматы образца, убирает его цветные заливки, подставляет данные новой карты и добавляет лист последним. Для пересчёта формул экспортируемая книга помечается для полного пересчёта при открытии в Excel. У созданной задачи в дашборде доступен карандаш «Внести правки»: факт и комментарий сохраняются в её новый лист при экспорте.

Если файл не был загружен, экспорт создает новую книгу только с созданными картами в стандартной структуре `A1:J55`, без формул шаблона.

## Последние изменения интерфейса и внесение прогресса

- До загрузки данных левая панель показывает стартовый блок `Выбор дорожных карт`, кнопку выбора Excel и расположенные внизу команды `Новая дорожная карта` и `Сообщить о проблеме`.
- После загрузки Excel или создания первой карты стартовый блок заменяется рабочей навигацией: `Дашборд всех карт` и поисковый выбор дорожной карты.
- Выбор периода расположен в верхнем правом блоке основной области вместо прежнего текста `Раздел: ...`; в левой панели квартальный фильтр не показывается.
- Длинный список вкладок заменён раскрывающимся выбором карты с поиском по названию. Переход к общей сводке выполняется отдельной кнопкой `Дашборд всех карт`.
- В раскрывающемся списке слева от названия каждой карты показывается цветной круг её текущего статуса; статусы пересчитываются при смене периода, а название статуса доступно во всплывающей подсказке.
- Шестерёнка `Настройки и действия` закреплена в самом низу боковой панели справа и отделена от навигации тонкой линией. До загрузки данных она скрыта.
- Шестерёнка открывает выдвижную панель с группами `Работа с картами`, `Источник данных` и `Поддержка`; панель закрывается крестиком, по затемнённому фону или клавишей `Esc`.
- Синяя точка на шестерёнке обозначает новые карты или несохранённые правки прогресса.
- В рабочем режиме под шестерёнкой находятся действия и источник Excel, которые до загрузки файла частично представлены на стартовом экране.
- Для загруженной существующей ДК в карточке `Статус плана` есть иконка карандаша в правом верхнем углу. При наведении она показывает подсказку `Внести правки`.
- Карандаш открывает окно внесения прогресса. Для количественной карты пользователь вводит накопительный факт, для этапной — объём выполненных этапов за выбранную неделю. При необходимости добавляется комментарий. По умолчанию выбрана текущая неделя; если текущая неделя не найдена, выбирается последняя прошедшая.
- Даты в таблицах и выборе недели приводятся к формату `дд.мм.гггг`, включая даты, пришедшие из Excel как строки в американском формате (`месяц/день/год`).
- Клик по затемнённому фону не закрывает ни мастер новой ДК, ни окно внесения прогресса. Закрытие доступно крестиком или кнопкой `Отмена`.
- После сохранения правки сразу отражаются в дашборде. Кнопка экспорта показывает число новых карт и/или правок.

### Экспорт правок прогресса

Инструмент по-прежнему не перезаписывает исходный Excel на диске. `Скачать Excel` создаёт файл `*_updated.xlsx`:

- Для загруженной книги экспорт работает с исходным XLSX-архивом, а не пересобирает все существующие листы через SheetJS. Поэтому оформление, формулы, объединённые ячейки, настройки печати и остальные части прежних ДК сохраняются.
- для количественных ДК записывает факт и комментарий в исходные колонки `Выполнено` / `Комментарий` (обычно I/J);
- для этапных ДК использует фактические колонки этих полей в листе (например, G/H);
- формулы процентов не заменяются;
- дополнительные листы новых ДК добавляются в эту же экспортируемую копию.

Технически экспорт использует `XLSX.CFB` для точечного изменения XLSX-архива. При записи обязательно указан `fileType: "zip"`; без этого библиотека создаёт OLE-контейнер, который Excel не распознаёт как `.xlsx`.

Проверенный сценарий:

1. Загрузить исходный Excel.
2. Создать и заполнить новую ДК.
3. Скачать файл `*_updated.xlsx`.

В результате новая ДК добавляется отдельным листом, а исходные ДК сохраняют корректное отображение. Не использовать ранее сформированные повреждённые `*_updated.xlsx` как исходные файлы для повторной загрузки.

## Отчёт для руководителя

В выдвижной панели `Настройки и действия` находится кнопка `Отчёт для руководителя`. Решение полностью локальное и не требует сервера, SMTP, паролей или настройки Microsoft Graph.

Сценарий:

1. Пользователь загружает Excel и выбирает квартал в основном фильтре.
2. Нажимает `Отчёт для руководителя`.
3. В модальном окне проверяет автоматически сформированные тему и текст.
4. При необходимости редактирует текст вручную.
5. Нажимает `Скопировать отчёт` либо `Открыть письмо`.
6. `Открыть письмо` использует ссылку `mailto:` и передаёт последний предпросмотр в почтовую программу по умолчанию. Финальную отправку пользователь подтверждает самостоятельно.

Отчёт формируется по всем задачам выбранного квартала. При значении `Все кварталы` используется годовая сводка. Активная вкладка отдельной задачи на состав отчёта не влияет.

В отчёт входят:

- период и дата формирования;
- количество отобранных задач;
- количество задач по статусам;
- средний прогресс;
- до заданного количества отстающих задач;
- название, величина отставания и ответственный.

Emoji в тексте не используются из-за несовместимости с некоторыми корпоративными шрифтами и версиями Outlook. Статусы обозначаются текстовыми маркерами:

- `[ВЫПОЛНЕНО]`;
- `[ПО ПЛАНУ]`;
- `[ОПЕРЕЖЕНИЕ]`;
- `[ОТСТАВАНИЕ]`;
- `[НЕТ ДАННЫХ]`.

### Фильтры отчёта

Внутри окна отчёта доступны независимые фильтры:

- ответственный;
- статусы;
- конкретные задачи;
- максимальное количество задач в блоке `Требуют внимания`.

Изменение любого фильтра сразу пересобирает текст и статистику. Рядом с фильтрами отображается счётчик `В отчёте: N из M`. Отключённые статусы удаляются из текста сводки.

Основной дашборд при этом не меняется. Уже открытый черновик Outlook обновить из браузера невозможно, поэтому фильтры нужно настроить до нажатия `Открыть письмо`.

Код фильтров отчёта отмечен комментариями `REPORT_FILTERS_START` / `REPORT_FILTERS_END`. Это позволяет убрать фильтры отдельно, не удаляя базовое формирование письма.

## Выравнивание карточек задач

Исправлена раскладка карточек на вкладке `Все задачи` при переключении между `Все кварталы` и отдельным кварталом:

- название задачи занимает одну строку; длинный текст сокращается многоточием и прокручивается при наведении;
- длинные названия не сдвигаются при появлении квартального бейджа;
- цветной индикатор статуса всегда расположен справа сверху;
- индикатор отображается также для статусов `Выполнено` и `Нет данных`;
- ответственный расположен в компактной строке метаданных;
- при пустой `A2` отображается `Ответственный: не указан`, поэтому нижние элементы карточек начинаются на одной высоте;
- отметка `Выполнено` показывается отдельным зелёным бейджем;
- в состоянии `Выполнено ранее` итоговый факт и квартал завершения занимают две колонки без отдельного дублирования даты.

Для средних размеров окна (`981–1250 px`) верхний заголовок и служебный статус располагаются друг под другом, а карточки показателей — по две в ряд. Это предотвращает переносы и смещение блоков при длинных названиях.
